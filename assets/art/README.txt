Final art goes in this folder.

Rules (see the HTML Prototype Task List, "Art placeholders and final art"):
1. Exact file name from the registry, lowercase, .png  (e.g. crystal-pebble.png, ring.png, bg-workshop.png)
2. Same aspect ratio as the registry size (1x or 2x resolution both fine)
3. Same anchor: centre for everything except backgrounds and title (top left)
4. Crystals in light grey on transparency - the game tints them
5. Buttons without text - the game draws the labels (Run, Activate) from text.json

Any file missing here is drawn as a code placeholder. After adding files, reload with Ctrl+F5.
To get the new art into play.html (the double-click version), run `python build.py` and commit play.html.
The full list of expected names is ART_REGISTRY in src/assets.js.
